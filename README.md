# Learning-Dashboard · 学习工作台

一个**单文件、零依赖、断网可用**的学习目标与专注时长管理台。

仿照番茄钟类 App 的形态，但只做**正向计时**——记录真实投入，而不是用倒计时逼你。

---

## 在线版（可安装到手机主屏幕）

**https://09db56bcee8944149e243bac5c1fc74b.sg.agentos-app.run**

手机 Chrome 打开 → 右上角 **⋮** → **安装应用**。装完是隐藏地址栏的独立应用，断网也能打开。

> 链接由云端沙箱托管，随时可能失效。要长期保留请用下面的本地版，或自己 fork 后重新部署。

## 本地版（单个 HTML 文件）

下载 `学习工作台.html`，双击即可用。不需要服务器、不需要联网、不请求任何外部资源。

> ⚠️ 用 `file://` 直接打开时，浏览器**不会**提供「添加到主屏幕」——Chrome 只对 `http(s)`
> 页面开放这个能力，这是浏览器限制，跟文件本身无关。想装成 App 请用在线版。

## 功能

| 模块 | 内容 |
|---|---|
| **目标** | 时长型（今日 60 分钟）/ 计数型（本周 2 本）两类目标；8 款内置海报（纯 CSS 渐变 + 内联 SVG） |
| **倒数日** | 目标页右上角常驻，只显示距今最近的一个（≤7 天变红、≤30 天变黄）；点开可管理全部，支持增删改 |
| **专注** | 正向计时、环形进度、名言、学霸模式（全屏无干扰，长按 3 秒退出） |
| **统计** | 累计 / 今日双卡、内联 SVG 饼图、日 / 周 / 月 / 全部 / 自定义区间、各目标占比、每日趋势、最近记录 |
| **设置** | 主题（跟随系统 / 亮 / 暗）、导出 JSON、**覆盖确认后**导入、旧版本迁移、清空示例、输入「清空」清空全部 |
| **布局** | 手机底部四 Tab · 平板顶部横向导航 · 电脑左侧固定边栏 + 多栏 |
| **数据** | 全部存在浏览器 `localStorage`，不上传任何服务器；带 `schemaVersion` 升级链，旧数据自动迁移 |

图标**全部是内联 SVG**，没有一个 emoji。

```

构建发布目录.js            构建脚本 —— 生成下面的 发布/ 目录

  ├─ manifest.webmanifest    PWA manifest

  ├─ icon-512.png
  └─ icon-maskable-512.png
备份/                      数据备份（App 里「导出 JSON」的产物）
  ├─ README.md               备份说明与恢复步骤

```

## 数据备份与恢复

App 的数据存在浏览器 `localStorage` 里，**绑定在你访问的那个网址上**——换设备、换浏览器，
或网址失效后重新部署，数据都不会自动跟过来。

因此：**定期在 App 里「设置 → 导出 JSON」，把导出的文件放进 `备份/` 目录。**

恢复时在 App 的「设置 → 导入 JSON」选中该文件即可，任何设备、任何部署方式都能还原。
详见 [`备份/README.md`](备份/README.md)。

## 重新构建

改完 `学习工作台.html` 之后：

```bash
node 构建发布目录.js
```

会重新生成整个 `发布/` 目录。图标是用**纯 Node 手写的 PNG 编码器**（内置 `zlib` + 自实现
CRC32）现场画出来的，**没有任何 npm 依赖**，不需要 `npm install`。

## 技术要点

- **零依赖**：不用任何框架、CDN、外部字体、图片文件；`grep` 不到一个外部 URL
- 海报 = CSS 渐变 + 内联 SVG `data-URI`
- 饼图 / 趋势图 = 手写 SVG 路径，没有图表库
- 计时 = 时间戳差值（`Date.now()`），**锁屏、切后台、息屏都不丢时长**；运行态落盘，重开可恢复
- 数据层 = `MIGRATIONS[n]` 升级链 + `normalize()` 容错（非法字段回落、未知字段保留不静默丢弃）
- 存储探测 = 启动时 `probeStorage()`，不可用时顶部常驻警告条，不静默失败
