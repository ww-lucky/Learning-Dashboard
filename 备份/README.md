# 备份

存放从 App 里「**设置 → 导出 JSON**」导出的数据备份。

## 文件命名

```
学习工作台-YYYY-MM-DD.json
```

日期为导出当天。

## 如何恢复

1. 用手机 Chrome 打开在线版：<https://09db56bcee8944149e243bac5c1fc74b.sg.agentos-app.run>
2. 进入 **设置 → 导入 JSON**
3. 选中这里的某个备份文件
4. 在弹出的差异对照表里确认，点「覆盖导入」

> ⚠️ 导入会**覆盖**当前全部数据，且不可撤销。导入前建议先导出一份当前的。

## 为什么必须备份

App 的数据存在浏览器 `localStorage` 里，**绑定在「你访问的那个网址」上**。
换设备、换浏览器，或者网址失效后重新部署，数据都不会自动跟过来。

导出的 JSON 是唯一能在不同环境之间搬运数据的载体——**任何设备、任何部署方式，导入即可恢复**。
